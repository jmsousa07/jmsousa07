## 📂 Projetos

### [dataset-libras](https://github.com/jmsousa07/dataset-libras)
Dataset de sinais em Libras para Machine Learning: 10 sinais × 9 sinalizadores × 3 repetições.
Pipeline em Python + MediaPipe que extrai 422 atributos por frame (21 landmarks × 2 mãos) de
49.506 frames, com metadados versionados e auditoria de qualidade por amostra.

### [scipath](https://github.com/jmsousa07/scipath)
Plataforma de publicação de material científico — backend Java 21 + Spring Boot 3 + PostgreSQL,
contrato OpenAPI como fronteira, 5 migrações Flyway e 42 arquivos de teste; frontend em Next.js.

### [automacao-de-tarefas](https://github.com/jmsousa07/automacao-de-tarefas)
Automação web em Python + Selenium com Page Object Model, logging estruturado e tratamento de
exceção por registro.

### [numerical-cauculus](https://github.com/jmsousa07/numerical-cauculus)
Notas de aula e implementações dos métodos do Cálculo Numérico — em construção.
